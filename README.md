## Sinossi

Applicazione VR formativa in prima persona, per visore e desktop, pensata per studenti e sviluppatori alle prime armi. L'utente è un tirocinante che deve riparare videogiochi difettosi: con le mani e un tablet diagnostico manipola direttamente i parametri del game engine, in tre lezioni successive — collisioni (*Super Mario 64*), game audio (*Minecraft*) e combat system (*Zelda*).
